# CERTIPRO 360 · Organismo Certificador Oficial SEP / CONOCER

Landing page oficial de **CERTIPRO 360** (Clave de acreditación: `CE1979-OC063-18`), diseñada para la captación de profesionales, consultores y creadores que buscan formalizar su experiencia técnica y docente bajo estándares federales de la SEP y el CONOCER en México.

## 🚀 Características Principales

- **Landing Page de Alta Conversión:** Estructura optimizada para captación de clientes (leads) con integración directa a WhatsApp.
- **Centro de Control Multicanal:** Reproductores multimedia integrados para video masterclass y podcast explicativo.
- **Transparencia Institucional:** Sección del ecosistema de confianza con enlaces de verificación oficial (SEP, CONOCER, RENAP, ICEMéxico).
- **Catálogo de Estándares de Competencia:** Detalle metodológico e inversiones para los estándares **EC0366**, **EC0301**, **EC0217.01** y **EC076**.
- **Cronómetro de Urgencia:** Contador regresivo dinámico que almacena el límite de tiempo en `localStorage`.
- **Diseño Responsive & Fluid Animations:** Desarrollado con CSS Grid, Flexbox e `IntersectionObserver` para animaciones livianas sin librerías pesadas.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Marcado semántico y reproductor de medios integrado.
- **CSS3:** Sistema de diseño personalizado mediante variables CSS, tipografías corporativas (*Plus Jakarta Sans* y *DM Mono*) e iconografía de *FontAwesome*.
- **JavaScript (Vanilla):** Lógica del temporizador de lanzamiento, menú flotante inteligente, acordiones FAQ interactivos, reproducción mutuamente excluyente de audio/video y redirección automatizada a WhatsApp.
